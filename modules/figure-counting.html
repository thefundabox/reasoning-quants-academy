Formulas That Replace Counting

For regular figures, don't count — compute. For irregular ones, count by SIZE class and add.

Squares in an n × n grid
1² + 2² + … + n²
3×3 grid → 9 + 4 + 1 = 14 squares.
Rectangles in an r × c grid
C(r+1,2) × C(c+1,2)
2×3 grid → C(3,2) × C(4,2) = 3 × 6 = 18. (Count includes all squares.)
Triangles from an apex fan
base split into n parts → n(n+1)/2
4 base parts → 10 triangles. Two parallel levels? Multiply by the levels.
Square with both diagonals
4 small + 4 large = 8
Add the two midlines → it becomes 16 (8 small + 4 medium + 4 large).
Counting by size class
When formulas don't fit, group: "1-part figures", "2-part figures", "4-part figures"… then add. Never eyeball randomly.
Exam trap
Read the question: "triangles", "squares", or "rectangles"? In a square grid, every square is also a rectangle — the counts differ!
